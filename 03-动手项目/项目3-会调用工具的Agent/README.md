# 项目 3 · 会调用工具的 Agent

**目标**：手写一个循环，让模型能查时间、算数、读文件，撞上错误能自己改。

## 为什么先手写，再用框架

框架会把 `while` 循环藏起来。看不见循环，就永远调不好 Agent——你不知道它为什么绕圈、为什么调错工具、为什么会把 500 行工具输出全塞进上下文。

## 怎么跑

```bash
pip install -r ../项目1-命令行聊天机器人/requirements.txt
python agent.py "帮我算下 128*7 等于多少，再看看当前时间"
```

## 验收标准

- [ ] 三个工具（时间、计算器、读文件）都能被正确调用
- [ ] 工具报错时，模型能根据错误信息修正（例如文件不存在 → 换一个）
- [ ] 有 `max_steps`，超过就停并说明原因
- [ ] 每步打印 `thought / action / observation`
- [ ] 读文件工具限制在 `sandbox/` 目录内，不能读系统文件

## 三个必须做的实验

1. 让它读一个不存在的文件 → 看它怎么反应
2. 把 `max_steps` 改成 2 → 看它半路停下说什么
3. 把工具描述改模糊（"查询信息"）→ 看调用准确率怎么掉
