# 项目 5 · 每日简报 Agent

**目标**：把前面学的东西合成一个真正每天在用的东西——定时抓取 → 摘要 → 推送。

## 架构

```
定时器(cron/手机闹钟) 
   → 抓取源（RSS / 网页 / 你的待办文件）
   → 去重 + 过滤（只要今天新增）
   → 模型摘要（固定模板，限制长度）
   → 推送（手机通知 / 邮件 / 写入文件）
```

## 怎么跑

```bash
pip install feedparser openai python-dotenv   # RSS 用
python brief.py --dry-run     # 只打印，不推送
```

## 验收标准

- [ ] 每天早上自动跑（cron 或 Tasker/手机定时任务）
- [ ] 输出固定结构：3 条要闻 + 1 条值得读的长文 + 今天的第一件事
- [ ] 抓取失败时不留空白，给出"今天抓取失败"的明确提示
- [ ] 连续跑 7 天，没有重复推送同一条

## 提示词要点

```text
你是我的信息助理。基于下面 10 条原始条目，输出：

1. 三条今天最值得知道的（每条一句话，不超过 40 字，必须带来源）
2. 一条值得深读的（给出为什么值得读）
3. 一条我可以直接忽略的（说明为什么是噪音）

规则：只依据给定条目；不确定的不要写；总长度不超过 200 字。
```
