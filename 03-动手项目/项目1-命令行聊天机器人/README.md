# 项目 1 · 命令行聊天机器人

**目标**：把 API 用到"顺手"的程度——多轮、流式、参数可调、看得见花费。

## 怎么跑

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # 填 key
python hello_llm.py "你好"
python chat.py
```

## 验收标准

- [ ] 能连续对话 10 轮，上下文不丢
- [ ] 输入 `/reset` 清空历史，`/temp 0.3` 改温度，`/cost` 看花费
- [ ] 输出是流式的（字一个个出现）
- [ ] 历史超过 20 轮会自动摘要压缩（第 2 周进阶）

## 分阶段任务

**v1（第 1 周）**：单轮问答跑通 → 改成 while 循环存历史
**v2（第 2 周）**：加流式、加命令、加用量统计、加历史压缩

## 学习点

| 你会撞上的问题 | 对应原理 |
|---|---|
| 聊久了变慢变贵 | 上下文窗口与成本（第 6 篇） |
| 它忘了前面说的 | 工作记忆只在上下文里 |
| 改成 0.0 还是偶有差异 | 采样并非绝对确定 |
| 中文回答比英文贵 | token 化（第 2 篇） |
