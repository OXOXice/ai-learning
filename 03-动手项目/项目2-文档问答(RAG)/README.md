# 项目 2 · 文档问答（RAG）

**目标**：让模型回答"它没训练过、但你有"的内容，并且**答不出来时说不知道**。

## 流水线

```
文档 → 切块 → 向量化 → 存库
问题 → 向量化 → 检索 top-k → 拼进上下文 → 生成（带引用）
```

## 怎么跑

```bash
pip install -r ../项目1-命令行聊天机器人/requirements.txt
# 把 3 份自己的文档放进 docs/
python rag.py
```

## 验收标准

- [ ] 问文档里有的内容，答案正确且**给出引用片段**
- [ ] 问文档里没有的内容，回答"资料中没有提到"，而不是编
- [ ] 换 3 种问法（同义改写）都能答对
- [ ] 能说出切块大小为什么选 500 字

## 三件必须自己想清楚的事

1. **切块多大**：太小丢上下文，太大检索不准、还贵。500–800 字 + 50 字重叠是常用起点
2. **检索几条**：top-3 通常够；太多会稀释注意力，还容易把无关内容当依据
3. **答不出来怎么办**：必须有"拒答"分支，否则 RAG 只是让幻觉更有说服力

## 进阶

- 加**重排**（rerank）：先粗召回 20 条，再精排取 3 条
- 加**混合检索**：关键词 + 向量，中文专有名词场景提升明显
- 加**多轮追问**：把上一轮问题和答案一起向量化去检索
