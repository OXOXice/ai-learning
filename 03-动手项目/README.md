# 动手轨：五个项目

原则：**每个项目都要能给别人用**。能跑起来的 30 行，胜过看懂 300 行。

| 项目 | 周次 | 学到什么 | 验收 |
|---|---|---|---|
| [1 命令行聊天机器人](项目1-命令行聊天机器人/) | 1–2 | API 调用、多轮历史、流式、参数 | 能连聊 10 轮不崩 |
| [2 文档问答 RAG](项目2-文档问答(RAG)/) | 4 | 切块、向量检索、引用、拒答 | 能准确回答自己 3 份文档 |
| [3 会调用工具的 Agent](项目3-会调用工具的Agent/) | 5–6 | 工具声明、循环、错误回传、记忆 | 完成 5 步以上任务，失败能恢复 |
| [4 AI 编程工作流](项目4-AI辅助编程工作流/) | 7 | 用 AI 写完整项目、审查、验证 | 一份自己的 SOP |
| [5 每日简报 Agent](项目5-每日简报Agent/) | 8 | 定时、抓取、摘要、推送 | 每天自动跑并推到手机 |

## 通用约定

- 每个项目一个目录，有自己的 `README.md`（写清怎么跑、依赖、已知问题）
- API key 放 `.env`，永不进 git
- 代码里必须打印 token 用量
- 每个项目至少 5 条"我踩过的坑"，写在 README 最后
