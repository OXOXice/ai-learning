# 课程与书单

## 免费、必看（按顺序）

| 资源 | 形式 | 花多久 | 为什么看 |
|---|---|---|---|
| 3Blue1Brown《但什么是 GPT / 注意力》 | 视频 1h | 2 天 | 建立直觉，第 1–2 周看 |
| Jay Alammar《The Illustrated Transformer》 | 图文 | 2 小时 | 架构图最清楚，第 2 周 |
| Karpathy《Intro to LLMs》 | 视频 1h | 1 天 | 全局观，什么时候看都行 |
| Anthropic《Building effective agents》 | 文章 | 1 小时 | Agent 工程视角，第 5 周必读 |
| OpenAI《Prompt engineering guide》 | 文档 | 2 小时 | 提示词基本功，第 3 周 |

## 想深入原理

- Karpathy《Let's build GPT》/《nanoGPT》：跟着写一遍，200 行
- 《Speech and Language Processing》第 3 版相关章节（免费在线）
- 李宏毅《机器学习》生成式 AI 系列（中文，讲得细）

## 想深入工程

- LangChain / LlamaIndex 官方文档（**先用纯 API 写，再用框架**）
- 《Designing Machine Learning Systems》（工程视角）
- 各家模型的 cookbook（OpenAI / Anthropic / DeepSeek）

## 不要看太多的东西

- 各种"7 天精通大模型"付费课：内容基本是本文档 + 抄官方文档
- 一上来就学 RAG 框架/向量库：先把"检索 + 拼上下文"手写一遍
- 追新模型榜单：对学习路径没有帮助
