# 工具清单

## 必装

| 工具 | 用途 |
|---|---|
| Python 3.10+ | 一切实验 |
| VS Code | 写代码，装 Python + Continue 插件 |
| `openai` SDK | API 调用（兼容多数国产模型） |
| `python-dotenv` | 管理 key |
| `rich` | 命令行好看一点，方便调试 |

## 按需

| 工具 | 什么时候用 |
|---|---|
| `tiktoken` | 数 token、估算成本 |
| `jupyterlab` | 边写边看输出 |
| `feedparser` | 项目 5 抓 RSS |
| Chroma / FAISS | 项目 2 数据量变大后 |
| LangChain / LlamaIndex | **手写过一遍之后**再用 |
| Cursor / Claude Code / Aider | 第 7 周开始用，做 AI 编程工作流 |

## 用 API 的通用配置

大多数工具都认这三个环境变量：

```bash
OPENAI_API_KEY=...
OPENAI_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-chat
```

配一次，CLI 工具、编辑器插件、自己的脚本都能复用。
