# 原理轨：AI 是怎么工作的

目标不是会写 Transformer 代码，而是**建立判断力**：知道模型为什么行、为什么不行、什么时候该信它。

| 篇 | 主题 | 一句话 |
|---|---|---|
| 01 | [大模型到底是什么](01-大模型到底是什么.md) | 它只做一件事：猜下一个 token |
| 02 | [Token 与向量](02-Token与向量.md) | 文字先被切碎、再变成坐标 |
| 03 | [注意力机制](03-注意力机制.md) | 每个词回头看别的词，决定该听谁的 |
| 04 | [Transformer 与生成](04-Transformer与生成.md) | 一堆注意力层叠起来，一个字一个字往外挤 |
| 05 | [模型是怎么训出来的](05-模型是怎么训出来的.md) | 先读遍互联网，再学听话，再学讨人喜欢 |
| 06 | [推理参数与成本](06-推理参数与成本.md) | 温度、top_p、上下文，直接决定钱和稳定性 |
| 07 | [幻觉与能力边界](07-幻觉与能力边界.md) | 幻觉不是 bug，是机制的副作用 |
| 08 | [Agent 是怎么工作的](08-Agent是怎么工作的.md) | 模型 + 工具 + 循环 + 停止条件 |
| 09 | [术语表](09-术语表.md) | 40 个词，一句话说清 |

每篇结构固定：**一句话总结 → 核心概念 → 动手实验 → 自测三问 → 延伸阅读**。实验必须亲手跑。
