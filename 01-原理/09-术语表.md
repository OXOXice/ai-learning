# 09 · 术语表

只收真正会用到的。每条一句话，看不懂就回对应篇章。

## 基础

| 术语 | 一句话 |
|---|---|
| Token | 模型处理的最小文本单位，介于字和词之间 |
| 词表 / Vocabulary | 所有 token 的集合，几万到几十万 |
| 嵌入 / Embedding | 把 token 或文本变成向量 |
| 向量维度 | 每个 token 用几个数字表示 |
| 余弦相似度 | 两个向量夹角的余弦，衡量语义接近程度 |
| 上下文窗口 / Context window | 一次能处理的最大 token 数 |
| 位置编码 / Positional encoding | 告诉模型 token 的先后顺序 |
| 注意力 / Attention | 让每个 token 按相关度吸收其他 token 的信息 |
| Q/K/V | 查询、键、值，注意力里的三个角色 |
| 多头注意力 / Multi-head | 并行做多组注意力，各学各的关系 |
| 前馈网络 / FFN | 每个 token 独立过的两层小网络，主要存知识 |
| 残差连接 / Residual | 把输入加回输出，让深层网络可训练 |
| LayerNorm | 归一化数值，稳定训练 |
| Transformer | 由注意力和 FFN 堆叠成的架构 |

## 训练

| 术语 | 一句话 |
|---|---|
| 预训练 / Pre-training | 在海量文本上学"预测下一个 token" |
| 基座模型 / Base model | 预训练的产物，只会续写，不会对话 |
| SFT | 用"指令-回答"样本微调，学会听指令 |
| RLHF | 用人类偏好训练打分器，再用强化学习调优 |
| DPO | 不用强化学习、直接用偏好对优化的对齐方法 |
| 对齐 / Alignment | 让模型行为符合人类意图与安全要求 |
| 蒸馏 / Distillation | 用大模型教小模型 |
| 量化 / Quantization | 降低权重精度以省显存 |
| LoRA / 微调 | 只训练少量附加参数来定制模型 |
| Scaling Law | 规模变大时损失按幂律下降的规律 |
| 过拟合 | 记住了训练数据、泛化变差 |
| 灾难性遗忘 | 微调新任务时忘掉旧能力 |

## 推理

| 术语 | 一句话 |
|---|---|
| 自回归 / Autoregressive | 一个 token 一个 token 地生成 |
| 采样 / Sampling | 按概率抽下一个 token |
| 温度 / Temperature | 控制采样随机程度 |
| top_p / 核采样 | 只在累计概率前 p 的候选里抽 |
| top_k | 只在前 k 个候选里抽 |
| 贪心解码 | 永远选概率最大的（温度 0） |
| 束搜索 / Beam search | 保留多条候选路径，翻译常用 |
| KV Cache | 缓存已算过的 K/V，加速生成 |
| 首字延迟 / TTFT | 从请求到第一个 token 的时间 |
| 吞吐 / Throughput | 每秒生成多少 token |
| 停止符 / Stop sequence | 命中就停止生成 |
| 思维链 / CoT | 让模型先写推理步骤再给答案 |
| 少样本 / Few-shot | 在提示里给几个示例 |
| 零样本 / Zero-shot | 只给任务描述，不给示例 |
| 上下文学习 / In-context learning | 靠上下文里的示例临时"学会"任务 |

## Agent 与工程

| 术语 | 一句话 |
|---|---|
| Agent | 模型 + 工具 + 循环 + 停止条件 |
| Function calling / 工具调用 | 模型输出结构化的工具调用请求 |
| ReAct | 思考与行动交替的循环模式 |
| 规划 / Planning | 先把任务拆成步骤再执行 |
| 记忆 / Memory | 把信息写到外部并重新读回上下文 |
| RAG | 检索相关片段塞进上下文再回答 |
| 分块 / Chunking | 把长文档切成适合检索的片段 |
| 向量库 | 存向量、做相似度检索的数据库 |
| 重排 / Rerank | 对初步检索结果再精排 |
| MCP | 模型与工具/数据源之间的标准协议 |
| 多智能体 / Multi-agent | 多个 Agent 分工协作 |
| 评测 / Eval | 用固定测试集量化效果 |
| 回归测试 | 改完提示词/模型后重跑，防止变差 |
| 越狱 / Jailbreak | 诱导模型绕过安全限制 |
| 提示注入 / Prompt injection | 把恶意指令藏在被处理的数据里 |
| 护栏 / Guardrail | 输入输出两侧的检查与限制 |
