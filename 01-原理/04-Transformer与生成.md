# 04 · Transformer 与生成过程

## 一句话总结

把几十层「注意力 + 前馈网络」摞起来，配残差和归一化，模型就有了一条从 token 序列到"下一个 token 概率"的稳定流水线；生成就是沿着这条流水线一个字一个字往外挤。

## 核心概念

### 1. 一层里发生了什么

```
输入 x
 ├─> LayerNorm → 多头注意力 → 加回 x      （残差）
 ├─> LayerNorm → 前馈网络(FFN) → 加回 x    （残差）
输出
```

- **注意力**：token 之间交换信息（横向）
- **FFN**：每个 token 自己过一遍小网络，做特征变换（纵向），常被理解为"存知识的地方"
- **残差连接**：`输出 = 子层(输入) + 输入`，让梯度能穿过几十层，深层网络才训得动
- **LayerNorm**：把数值拉回稳定范围，不然深层会爆炸/消失

### 2. 为什么"深"有用

浅层学局部语法搭配，中层学句法和指代，深层学语义和任务相关模式。层数越多，能表达的"抽象层级"越多。这也是"大模型"里"大"的一半含义（另一半是宽度/参数量）。

### 3. 生成：一次只出一个 token

```
prompt → [模型] → 下一个 token 的概率 → 采样一个 → 拼回 prompt → 重复
```

关键工程优化：
- **KV Cache**：前面 token 的 K/V 算过就存起来，生成第 n 个时不用重算前 n-1 个，否则每多一个字都要全量重算
- **预填充 vs 解码**：读 prompt 是并行的（快），逐字生成是串行的（慢）。所以"首字延迟"和"生成速度"是两个不同指标
- **停止条件**：遇到结束符、达到 `max_tokens`、或命中停止词

### 4. 温度与采样（详见第 6 篇）

模型给的是概率表，最终选谁由采样策略决定。同一张表，`temperature=0` 取最大概率（稳但死板），`temperature=1.2` 抽样更随机（活但容易跑偏）。

### 5. 三个常见误解

| 误解 | 实际 |
|---|---|
| 模型一次性想好整段再输出 | 它是逐 token 生成，后面的内容受前面已生成内容影响 |
| 模型能"看到"后面的内容再修改 | 不能。写错了只能重来 |
| 更大的模型一定更准 | 知识更广，但幻觉不会自动消失；可靠性来自使用方式（检索、验证） |

## 动手实验

### 实验 1：亲眼看到逐 token 生成

```python
from openai import OpenAI
client = OpenAI()
stream = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "写一段 100 字的春天描写"}],
    stream=True,
)
for chunk in stream:
    delta = chunk.choices[0].delta.content
    if delta:
        print(delta, end="", flush=True)
```

**观察**：字是一个个蹦出来的，不是整段出现。这就是自回归的物理证据。

### 实验 2：改写 vs 重生成

让它写一段话，然后要求"把第 3 句改得更口语"。
**观察**：它其实是**重写了整段**（甚至改动了别处），因为"修改"对它是"生成一段新的、包含修改的文本"。

### 实验 3：长度失控

故意让它"详细展开"，看它何时停。再设 `max_tokens=50`，观察被硬切断的效果（句子半截）。
