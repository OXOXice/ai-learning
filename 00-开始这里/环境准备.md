# 环境准备（30 分钟搞定）

## 1. Python

需要 3.10 以上。检查：

```bash
python3 --version
```

## 2. 一个模型 API

不用本地显卡，直接调 API 最省事。任选一家（都兼容 OpenAI 格式）：

| 服务 | 特点 | 地址 |
|---|---|---|
| DeepSeek | 便宜、中文好，适合大量练习 | `https://api.deepseek.com` |
| 通义千问 | 有免费额度 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱 GLM | 有免费额度 | `https://open.bigmodel.cn/api/paas/v4` |
| OpenAI | 最通用，但要走代理 | `https://api.openai.com/v1` |

拿到 key 后**不要写进代码**，写进 `.env`：

```bash
# .env（这个文件不进 git，已经在 .gitignore 里）
OPENAI_API_KEY=sk-xxxxxxxx
OPENAI_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-chat
```

> Agent 工具（Claude Code / Cursor / 各种 CLI）大多也认这套 `BASE_URL + KEY`，配一次能到处用。

## 3. 项目初始化

```bash
cd 03-动手项目/项目1-命令行聊天机器人
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## 4. 跑通第一句

```bash
python hello_llm.py "用一句话解释什么是 token"
```

看到回答就说明路通了。看不到，按报错查：

| 报错 | 原因 |
|---|---|
| `AuthenticationError` | key 错或没加载 `.env` |
| `Connection error` | 网络/代理；`BASE_URL` 写错 |
| `model not found` | `MODEL_NAME` 和这家服务对不上 |
| `insufficient balance` | 账户没余额 |

## 5. 编辑器

- **VS Code**：插件 `Python` + `Continue`（免费，能接自己的 API）
- **Cursor / Claude Code**：第 7 周用，现在先别依赖，先把原理搞懂
- **Jupyter**：做实验时方便，`pip install jupyterlab`

## 6. 花钱的边界

第 1 周建议给账户充 **10–20 元**，够跑完所有练习。看住两件事：

- 每次调用都打印 `usage.total_tokens`，心里有数
- 循环里别调模型（Agent 最容易在这里烧钱），加最大轮数上限
